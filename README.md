# Blinkit Grocery Sales Analysis 🛒📊

## Project Overview
This project performs an end-to-end data analysis of Blinkit's grocery sales data using **PostgreSQL**. The goal is to extract actionable business insights regarding store performance, product category trends, and customer purchasing behaviors. 

By taking raw, unformatted data and transforming it through a structured SQL pipeline, this project demonstrates real-world data cleaning, KPI metric development, and advanced analytical querying.

## Tech Stack
* **Database:** PostgreSQL (pgAdmin 4)
* **Techniques:** Data Staging, Data Type Casting, CTEs, Window Functions (`DENSE_RANK`, `SUM() OVER()`), Conditional Logic (`CASE`), Aggregations.

## Data Cleaning & Staging 🧹
Raw data was imported into a `TEXT` staging table to prevent import errors caused by missing values or inconsistent formatting. A cleaned production table (`blinkit_cleaned`) was then generated by:
1. Standardizing messy categorical data (e.g., merging 'LF', 'low fat', and 'Low Fat' into a uniform 'Low Fat' label).
2. Casting string columns into proper `NUMERIC` and `INT` data types using `NULLIF()` to handle empty strings safely.

## Key Business Insights 📈

* **Outlet Format Dominance:** Supermarket formats drive the overwhelming majority of revenue. A single Tier 3 Supermarket (`OUT027`) is responsible for **18.58%** of the entire company's sales volume ($3.45M), whereas standard Grocery Stores contribute less than 1% each.
* **Top-Grossing Categories:** **Fruits & Vegetables** ($2.82M) and **Snack Foods** ($2.73M) are the highest revenue-generating categories, comprising nearly 30% of total platform revenue.
* **Health-Conscious Purchasing:** **Low Fat** items dominate customer preference, accounting for roughly 64% of total sales ($11.90M vs. $6.69M for Regular fat content).

## Highlighted SQL Queries 💻

### 1. Advanced Window Function: Store Revenue Contribution
Calculated the exact percentage share each outlet contributes to total company revenue in a single pass without subqueries.
```sql
SELECT 
    outlet_identifier,
    outlet_type,
    outlet_location_type,
    ROUND(SUM(item_outlet_sales), 2) AS outlet_revenue,
    ROUND(
        (SUM(item_outlet_sales) * 100.0) / SUM(SUM(item_outlet_sales)) OVER (),
        2
    ) AS pct_contribution_to_total
FROM blinkit_cleaned
GROUP BY outlet_identifier, outlet_type, outlet_location_type
ORDER BY outlet_revenue DESC;
